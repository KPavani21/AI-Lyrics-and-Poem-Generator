
# AI Lyrics and Poem Generator 🎵

An AI-powered web application that generates creative song lyrics and poems based on user-selected themes, emotions, and writing styles.

## Features

- Generate song lyrics and poems using AI.
- Multiple writing styles and emotions.
- Supports English, Telugu, and Hindi.
- Generate creative content using Google Gemini API.
- Save and view previous creations.
- Add favourite creations.
- Download generated content as TXT and PDF.
- Improve, regenerate, and translate content.

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- SQLite
- ReportLab

## Installation and Setup

1. Clone the repository:

   git clone https://github.com/KPavani21/AI-Lyrics-and-Poem-Generator.git

2. Open the project folder:

   cd AI-Lyrics-and-Poem-Generator

3. Install dependencies:

   pip install -r requirements.txt

4. Create `.streamlit/secrets.toml` and add your Gemini API key:

   GEMINI_API_KEY = "YOUR_API_KEY"

5. Run the application:

   streamlit run app.py

## Note

Keep your API key private. Never upload your secrets.toml file to GitHub.
